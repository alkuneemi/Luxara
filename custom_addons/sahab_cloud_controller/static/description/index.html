Sahab Cloud Controller

الموديول المركزي لإدارة منصة Sahab Cloud. يحول Odoo إلى لوحة قيادة سحابية متكاملة تدير دورة حياة حاويات العملاء عبر GitHub وRailway وn8n.

المميزات

  • إنشاء بيئات Odoo معزولة لكل عميل بضغطة زر واحدة
  • إدارة فروع GitHub تلقائياً لكل عميل
  • إيقاف واستئناف الحاويات فورياً عند التخلف عن السداد
  • بيئات اختبار (Staging) منعزلة مع نسخ احتياطية من البيانات الحقيقية
  • دمج وتطبيق التعديلات من بيئة الاختبار إلى الإنتاج
  • بوابة ويب للخدمة الذاتية للعملاء
  • إشعارات بريد إلكتروني آلية عند جاهزية المنصة
