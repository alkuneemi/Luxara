# Custom Addons — Luxara

هذا المجلد يحتوي على المديولات المخصصة لمشروع Luxara على Odoo 19.

## المديولات

| المديول | الوصف |
|---------|--------|
| insurance_broker_suite | نظام إدارة وسطاء التأمين — سجلات الطلبات والفرص والمبيعات |
| insurance_feedback | نظام ملاحظات المستخدمين مع تحليل OMAN AI Agent |

## تثبيت المديول

1. انسخ مجلد المديول إلى مسار addons في Odoo
2. اذهب إلى: الإعدادات ← تقني ← تحديث قائمة الوحدات
3. ابحث عن اسم المديول وثبّته
